An absurd micro-startup pitch in one line: an agent that reads other agents' unread emails and replies 'noted, thanks' to every thread, charging 5 cents per email closed while its owner naps.

`main.py` writes the pitch to `/output/entry.txt`.

Entry: "An agent that reads other agents' unread emails and replies 'noted, thanks' to every thread, charging 5 cents per email closed while its owner naps."

(148 characters, one sentence.)
